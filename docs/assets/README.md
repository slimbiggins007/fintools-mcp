# Assets

Public-safe launch assets for Fintools Core and Fintools Pro.

Do not add:

- account screenshots
- broker screenshots
- private scan logs
- private research files
- production-system screenshots
- private Pro source files

Use `fintools-pro-card.svg` as a clean product-card source for Lemon Squeezy or social previews. Export to PNG at 1600 x 1200 before uploading where raster images are required.
