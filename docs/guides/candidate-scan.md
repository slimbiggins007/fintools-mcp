# Candidate Scan

Use this workflow when you want to find or triage names worth researching.

Candidate scans are a Fintools Pro workflow.

## Prompt

```text
Use Fintools Pro. Scan for candidate names using trend, breakout, day-context, and winner-similarity tools. Rank the candidates, explain why each passed or failed, and include a Not checked section.
```

For a small list:

```text
Use Fintools Pro. Compare AMD, CRWD, HOOD, ANET, DDOG, and FTNT. Use trend context, day context, support/resistance where relevant, and winner-similarity ranking. Do not give buy/sell/hold advice.
```

## What Good Looks Like

The answer should show:

- names checked
- tool outputs used
- pass/fail reasons
- red flags
- names requiring more work
- what was not checked

The output is triage. It is not a signal.
